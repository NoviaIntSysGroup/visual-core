About This Project

The core's own example: three decks and ten figures, built only from shared parts. Open it to see a change to the core without a project, or copy this page to start a new one.

Present

Reveal.js decks with shared templates, an on-slide editor, and PDF export.

Publish

Figures on a centimetre canvas, exported as SVG, 600 dpi PNG, or vector PDF.

Reuse

A figure drops onto a slide or into another figure unchanged.
